# DIO Agent — Especialização em Cibersegurança (Python)

Este repositório estende o [DIO Agent](https://github.com/digitalinnovationone/dio-agent) com uma especialização em segurança da informação, seguindo o desafio da DIO.

## O que tem aqui

- **Duas skills de segurança**: análise de vulnerabilidade (formato fixo) e testes de segurança (contexto antes de comando).
- **Conhecimento**: fundamentos de segurança, tríade CID, MITRE ATT&CK, SQL Injection e boas práticas.
- **Persona especializada** e **AGENTS.md** com regra global de segurança.
- **Testes**: `app.py` vulnerável + `app_corrigido.py` parametrizado + `test_sqli.py`.

## Documentação completa

Veja [`README-seguranca.md`](README-seguranca.md) para detalhes, resultados dos testes e limitações conhecidas.
